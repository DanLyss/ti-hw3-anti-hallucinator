# Домашка 8: регулярные выражения

ANTLR4 → дерево разбора → ε-NFA Томпсона → удаление ε-переходов → DFA → точная эквивалентность с ground truth.

Перед полной детерминизацией ищется слово-контрпример (включая пустое): расхождение с ground truth строго доказывает неэквивалентность. Совпадение на конечной выборке не считается доказательством: для положительного вердикта всё равно нужна точная проверка DFA.

Проверяется весь сырой ответ. Markdown, пояснения и расширенный синтаксис не исправляются. Пробельные символы игнорируются грамматикой. Длина — число непробельных символов всего ответа, включая невалидные ответы; пустой ответ имеет длину 0. Проценты считаются от всех полученных ответов, а не только от валидных. Неоценённые из-за лимитов ответы показаны отдельно и не считаются доказанно корректными.

Основные тесткейсы: basic, 4th-symbol, employer, intersection. personal добавлен для сопоставления с прошлым экспериментом.

Все исходные ответы и параметры запросов хранятся в `data/raw_regex.tar.gz`. Для воспроизведения: `tar -xzf data/raw_regex.tar.gz`, затем команды из `README_hw8.md`.

## Конкретные доказательства ошибок

По одному найденному контрпримеру на пару модель × тесткейс. Это слова, на которых выражение и ground truth расходятся; ε означает пустое слово.

Возможное объяснение различий: выражения компактно задают повторение и позицию с конца (4th-symbol), а автомату нужна явная таблица переходов. Для intersection нужно сначала исключить операцию пересечения, для employer — выразить запрет SPB0 без lookahead. Это гипотезы о причинах, а не измеренные свойства моделей. Короткая запись сама по себе не доказывает корректность.

Лимиты: 10000 символов ответа, глубина скобок 100, до 20000 состояний при детерминизации. Сырые ответы и параметры запросов: `data/raw_regex/`; детальные вердикты: `data/results/runs_regex.jsonl`.
