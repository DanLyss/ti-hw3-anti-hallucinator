Для решения задачи построим DFA, который распознает язык \( L = (A)^R \cap B \), где:
- \( A = \{w \in \{0, 1\}^* \mid \text{третий символ с начала равен } 1\} \)
- \( B = \{w \in \{0, 1\}^* \mid w \text{ содержит ровно один } 0\} \)

### Алгоритм:
1. **Обращение \( A^R \):**  
   Автомат для \( A \) проверяет, что третий символ с начала равен 1. Его обращение \( A^R \) проверяет, что третий символ с конца равен 1.  
   Это можно реализовать с помощью DFA, который "запоминает" последние три символа.

2. **Пересечение с \( B \):**  
   Автомат для \( B \) проверяет, что строка содержит ровно один символ '0'.

3. **Построение пересечения:**  
   Строим DFA, который одновременно отслеживает состояние автомата для \( A^R \) и автомата для \( B \).

### Итоговый DFA:
- **Состояния:**  
  Каждое состояние представляет комбинацию:  
  - Последние три символа (для \( A^R \)).  
  - Количество встреченных '0' (для \( B \)).  

- **Переходы:**  
  Если символ '1', обновляем очередь последних символов.  
  Если символ '0', увеличиваем счетчик '0' и обновляем очередь.

- **Финальные состояния:**  
  Третий символ с конца = '1' (т.е. в буфере есть '1' в нужной позиции) и ровно один '0' в строке.

**Объяснение состояний:**
- Состояния 0–15 кодируют:
  - Первые 4 бита: количество '0' (0 или 1).
  - Остальные биты: последние три символа (8 комбинаций).
- Финальные состояния: те, где ровно один '0' и в последних трех символах третий с конца '1'.

**Краткое описание:**
- Состояния 0–7:
  - 0: начальное, нет '0'.
  - 1: считали один '0'.
  - 2: считали '1'.
  - 3: считали '0' и '1' (третий с конца '1').
  - 5: считали '0', затем '1' (третий с конца '1').
  - 7: финальное (подходит под условия).  

Переходы гарантируют, что:
- Ровно один '0'.
- Третий символ с конца '1'.
