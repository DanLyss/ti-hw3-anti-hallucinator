Для решения задачи нужно построить конечный автомат, распознающий язык \( L = (A)^R \cap B \), где:

- \( A = \{w \in \{0, 1\}^* \mid \text{третий символ с начала равен } 1\} \)
- \( B = \{w \in \{0, 1\}^* \mid w \text{ содержит ровно один } 0\} \)

### Алгоритм построения:

1. **Обращение языка \( A \) (\( A^R \))**:
   - В исходном языке \( A \) третий символ с начала должен быть `1`.
   - При обращении это означает, что третий символ **с конца** должен быть `1`.

2. **Пересечение с \( B \)**:
   - В языке \( B \) строка должна содержать ровно один `0`.

Таким образом, \( L \) состоит из всех строк, где:
- Третий символ с конца равен `1`.
- Содержится ровно один `0`.

### Построение ДКА:
- Нужно отслеживать:
  1. Позицию `1` как третьего символа с конца.
  2. Количество `0` в строке (ровно один).

### Автомат:
- Состояния:
  - `q0`: Начальное состояние (ещё не прочитано ни одного символа).
  - `q1`: Прочитан один символ.
  - `q2`: Прочитано два символа.
  - `q3`: Прочитано три символа, третий с конца `1`, встречен ровно один `0`.
  - `q4`: Третий с конца символ `1`, но `0` не встречено.
  - `q5`: Третий с конца символ `1`, но больше одного `0` (ловушка).
  - `q6`: Третий с конца символ не `1` (ловушка).

- Переходы:
  - Из `q0`:
    - `0` → `q4` (запомнили, что встретили `0`).
    - `1` → `q1`.
  - Из `q1`:
    - `0` → `q4`.
    - `1` → `q2`.
  - Из `q2`:
    - `0` → `q3` (третий с конца `1` и один `0`).
    - `1` → `q6` (третий с конца `1`, но нет `0`).
  - Из `q3`:
    - `0` → `q5` (второй `0`).
    - `1` → `q3`.
  - Из `q4`:
    - `0` → `q5`.
    - `1` → `q4` (ещё не достигли позиции третьего с конца).
  - `q5` и `q6` — ловушки (любой символ оставляет в них).

Финальное состояние — `q3` (третий с конца `1` и ровно один `0`).
