Для построения конечного автомата, распознающего язык \( L = (A)^R \cap B \), где:
- \( A = \{w \in \{0, 1\}^* \mid \text{третий символ с начала равен } 1\} \)
- \( B = \{w \in \{0, 1\}^* \mid w \text{ содержит ровно один } 0\} \)

### Анализ:
1. **Обращение языка \( A \)** (\( A^R \)) означает, что третий символ **с конца** должен быть \( 1 \).
2. **Язык \( B \)** требует, чтобы строка содержала ровно один \( 0 \).
3. Таким образом, \( L \) состоит из строк, которые:
   - Содержат ровно один \( 0 \),
   - И имеют третий символ с конца \( 1 \).

### Построение ДКА:
1. **Параметры языка \( B \)** (ровно один \( 0 \)) можно смоделировать, отслеживая:
   - Был ли уже встречен \( 0 \),
   - Иначе строка не принадлежит \( B \), если \( 0 \) встретится дважды.
2. **Параметры \( A^R \)** (третий символ с конца \( 1 \)) требуют, чтобы при прочтении последних трёх символов второй из них был \( 1 \).

### Автомат:
- **Состояния**:
  - \( q_0 \): Начальное состояние, \( 0 \) не встречен.
  - \( q_1 \): Встречен ровно один \( 0 \).
  - \( q_2 \): Встречено более одного \( 0 \) (ловушка для \( B \)).
  - Дополнительные состояния для отслеживания последних трёх символов.

### Реализация:
```plaintext
6
2
0
1
0 0 1
0 1 0
1 0 2
1 1 3
2 0 2
2 1 2
3 0 4
3 1 5
4 0 2
4 1 2
5 0 1
5 1 1
```

### Пояснение автомата (формально не требуется в ответе):
- **Состояния**:
  - \( 0 \): Начальное, \( 0 \) не встречен.
  - \( 1 \): Встречен ровно один \( 0 \).
  - \( 2 \): Ловушка для \( B \) (более одного \( 0 \)).
  - \( 3 \): После одного \( 0 \) и одного произвольного символа.
  - \( 4 \): После одного \( 0 \) и \( 0 \) (не подходит для \( A^R \)).
  - \( 5 \): После одного \( 0 \) и \( 1 \) (подходит, если следующий символ завершает строку).
- **Финальное состояние**: \( 1 \) (ровно один \( 0 \) и третий символ с конца \( 1 \)).
