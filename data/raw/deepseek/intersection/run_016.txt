**Пояснение (не включать в ответ):**  

Автомат построен для языка L = (A)^R ∩ B, где:  
- A = {w | третий символ с начала равен 1},  
- B = {w | w содержит ровно один 0}.  

**Структура автомата (DFA):**  
- **Состояния:**  
  - 0: начальное, не считано ни одного символа.  
  - 1: считан один символ (любой).  
  - 2: считано два символа, третий с конца должен быть '1' (ожидается ровно один '0' в оставшейся части).  
  - 3: считаны три или более символов, третий с конца — '1', но '0' уже встретился ранее (нарушение B).  
  - 4: финальное, строка удовлетворяет обоим условиям.  

**Переходы:**  
- Из 0: читает '0' -> переходит в 1 (запоминает, что '0' встречен), читает '1' -> остается в 0.  
- Из 1: читает '0' -> переходит в 3 (нарушение, так как '0' уже был), читает '1' -> переходит в 2 (ожидание конца строки).  
- Из 2: читает '1' -> переходит в 4 (финальное, так как строка заканчивается здесь и удовлетворяет условиям).  
- Из 3: читает '0' -> переходит в 3 (нарушение), читает '1' -> остается в 3.  
- Из 4: читает '1' -> остается в 4 (допускает любое количество '1' после единственного '0').  

Финальное состояние: 4 (строка содержит ровно один '0', и третий символ с конца — '1').
