Рассмотрим задачу построения конечного автомата для языка \( L = (A)^R \cap B \), где:

- \( A = \{w \in \{0, 1\}^* \mid \text{третий символ с начала равен } 1\} \)
- \( B = \{w \in \{0, 1\}^* \mid w \text{ содержит ровно один } 0\} \)

### 1. Понимание \( A \) и \( (A)^R \)
- **Язык \( A \)**: Слова, у которых третий символ с начала равен 1. Например: "110", "1010", "0011" (третий символ — 1).
- **Обращение \( (A)^R \)**: Теперь третий символ **с конца** должен быть 1. Например: "011" (третий с конца — 1), "0101" (третий с конца — 1).

### 2. Понимание \( B \)
- **Язык \( B \)**: Слова, содержащие ровно один символ '0'. Например: "0", "10", "0111", но не "00" или "1001".

### 3. \( L = (A)^R \cap B \)
Слова, которые:
- Имеют третий символ **с конца** равный 1,
- Содержат **ровно один** символ '0'.

### 4. Построение NFA
Автомат должен:
1. Проверить, что третий символ с конца — 1 (это можно сделать, запоминая последние три символа или используя недетерминизм).
2. Убедиться, что в слове ровно один '0'.

#### Структура автомата:
- Состояния будут отслеживать:
  - Позицию '1' как третьего символа с конца.
  - Количество '0' в слове (должно быть ровно 1).
- Используем недетерминизм, чтобы "угадать", какой символ является третьим с конца.

### Автомат:
- **Состояния**:
  - `q0`: Начальное состояние (ещё не прочитали ни одного символа).
  - `q1`: Прочитали первый символ (возможно, это третий с конца).
  - `q2`: Прочитали второй символ (возможно, это третий с конца — здесь должен быть '1').
  - `q3`: Прочитали третий символ (третий с конца — здесь должен быть '1').
  - `q4`: Прочитали '0' (ровно один раз).
  - `q5`: "Мусорное" состояние (если нарушены условия языка).

- **Переходы**:
  - Из `q0` можно перейти в `q1` (начало слова).
  - Из `q1` можно перейти в `q2` (второй символ с конца).
  - Из `q2` (третий с конца) переход по '1' в `q3`.
  - Из `q3` переходы по '0' или '1' (проверка, что '0' встречается ровно один раз).
  - Если '0' встречается повторно, переход в `q5`.

- **Финальные состояния**:
  - `q4`: Успешно прочитали слово с ровно одним '0' и третий символ с конца — '1'.

### Итоговый автомат:
```
6
2
0
4
0 0 1
0 1 1
1 0 2
1 1 2
2 0 5
2 1 3
3 0 4
3 1 3
4 0 5
4 1 4
5 0 5
5 1 5
```
