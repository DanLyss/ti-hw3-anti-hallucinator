Для построения конечного автомата для языка \( L = A^R \cap B \), где:
- \( A = \{w \in \{0, 1\}^* \mid \text{третий символ с начала равен } 1\} \),
- \( B = \{w \in \{0, 1\}^* \mid w \text{ содержит ровно один } 0\} \),
- \( A^R \) — обращение языка \( A \), то есть все слова из \( A \), записанные в обратном порядке.

### Алфавит:
- `0` → индекс 0
- `1` → индекс 1

### Автомат:
Он должен:
1. Принимать слова, обращённые к языку \( A \) (т.е. третий символ **с конца** равен `1`).
2. Содержать ровно один `0`.

### Построение:
- Состояния будут отслеживать:
  - Сколько `0` было встречено (0 или 1).
  - Позицию в слове относительно третьего символа с конца.

### Конечный автомат (DFA):

```
6
2
0
3
0 0 1
0 1 0
1 0 2
1 1 1
2 0 4
2 1 3
3 0 4
3 1 3
4 0 4
4 1 4
```

### Пояснение структуры (для проверки, в вывод не включать):
- **Состояния**:
  - `0`: начальное, `0` не встречено, не на третьей позиции с конца.
  - `1`: `0` не встречено, на третьей позиции с конца (ожидается `1`).
  - `2`: `0` встречено один раз, не на третьей позиции с конца.
  - `3`: `0` встречено один раз, на третьей позиции с конца (финальное, если символ `1`).
  - `4`: более одного `0` или нарушено условие третьего символа (ловушка).
- **Стартовое состояние**: `0`.
- **Финальное состояние**: `3` (ровно один `0` и третий символ с конца `1`).
