- `0` — начальное.  
- `1` — считан первый символ (любой).  
- `2` — считан второй символ (любой), и третий символ с конца (первый с начала в перевёрнутой строке) равен `1`.  
- `3` — обработан `0` в строке, и строка содержит ровно один `0` (для языка B).

Финальное состояние:  
- `4` — строка принадлежит языку (удовлетворяет обоим условиям).  

Переходы:  
- Из `0` по `1` в `1` (первый символ `1`).  
- Из `1` по `1` в `2` (второй символ `1`, третий с начала в исходной строке будет `1`).  
- Из `2` по `0` в `3` (единственный `0` в строке).

- Из `1` по `0` в `4` (если `0` встречен раньше третьего символа).
