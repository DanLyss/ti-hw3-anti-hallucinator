Для решения задачи построим детерминированный конечный автомат (DFA), распознающий ID сотрудника согласно заданным правилам. Алфавит состоит из 12 символов: букв A, M, C, S, P, B (первые 6 символов) и цифр 0-5 (последние 6 символов).

Автомат должен:
1. Принимать строки, начинающиеся с 3 букв региона (любые из A, M, C, S, P, B).
2. Затем идёт 4 цифры (0-5).
3. Если первые 3 буквы - SPB (S, P, B), то первая цифра не может быть 0.

Состояния:
- q0: начальное состояние
- q1: прочитана первая буква
- q2: прочитаны две буквы
- q3: прочитаны три буквы (регион)
- q4: первая цифра для не-SPB регионов
- q5: первая цифра для SPB регионов (не 0)
- q6: вторая цифра
- q7: третья цифра
- q8: четвёртая цифра (конечное состояние)

Финальное состояние - q8. Переходы учитывают условия для SPB.
