Чтобы построить двусторонний детерминированный конечный автомат (2DFA) для языка \( L = \{w \mid ww \in L(A)\} \), где \( L(A) \) — язык всех строк над алфавитом \(\{0, 1\}\), где не содержится подстроки "110", нужно выполнить следующие шаги:

1. **Построение автомата для \( L(A) \)** (отвергающего строки с "110").
2. **Проверка, что \( ww \) не содержит "110"** (используя движение влево-вправо для проверки конкатенации \( ww \)).

Вот 2DFA для данного языка:

```
5
2
0
4
0 2 1 1
1 0 1 1
1 1 2 1
1 3 4 1
2 0 1 1
2 1 3 1
3 0 1 1
3 1 0 -1
0 0 0 -1
0 1 0 -1
0 3 4 1
```

**Пояснение** (не включается в ответ):
- Состояния: 0 (начальное), 1 (движение вправо), 2 (после '1'), 3 (после '11'), 4 (принимающее).
- Алфавит: '0' (0), '1' (1), '⊢' (2), '⊣' (3).
- Автомат движется вправо, проверяя отсутствие "110" в \( ww \). Если обнаруживается "110", он отвергает строку. Если доходит до конца без "110", принимает.
