## Часть 2 — 2DFA (10 баллов)

### Этап 5 — Модель, формат, семантика
- [x] `TwoWayAutomaton`: переходы `(состояние, символ) → {(состояние, направление)}`, направление ∈ {−1, +1}.
- [x] **Семантика** (формат без концевых маркеров, поэтому фиксируем явно и пишем в промпт): головка стартует на первом символе; слово принято, если головка уходит **вправо за конец слова** в финальном состоянии; уход влево за начало, отсутствие перехода или зацикливание — отказ. Пустое слово принимается ⇔ стартовое состояние финальное. *Надо сверить с лекцией — см. открытые вопросы.*
- [x] Парсер (4 числа на переход) + валидатор: всё из домашки 3 (диапазоны, `n` и `m` посчитаны правильно) + направление строго ±1.
- [x] «Действительно 2DFA»: детерминизм (ровно один старт, ≤ 1 переход на пару (состояние, символ)) **и** есть хотя бы одно движение налево.
- [x] Симулятор 2DFA с обнаружением зацикливания (повтор конфигурации (состояние, позиция)).
- [x] Тесты: ручные 2DFA, включая зацикливание, уход за левый край, пустое слово.

### Этап 6 — 2DFA → DFA (7 баллов)
- [x] Конструкция Шепердсона через таблицы поведения: для префикса `w` храним, в каком состоянии автомат впервые выходит из `w` вправо при старте слева, и для каждого состояния `q` — в каком состоянии выходит вправо, если вошёл в последнюю клетку `w` справа в состоянии `q` (или ⊥: ушёл за левый край/завис/застрял). DFA-состояние = такая таблица, строим только достижимые BFS-ом. *Алгоритм сверить с лекцией.*
- [x] Обобщение на недетерминированные (таблицы → отношения), чтобы проверять на корректность все валидные по формату ответы, а не только детерминированные.
- [x] Тесты: результат конвертации эквивалентен исходному 2DFA на полном переборе слов (через симулятор этапа 5); 2DFA без движений налево → совпадает с обычным DFA; ручной пример с подсчитанным числом состояний.
